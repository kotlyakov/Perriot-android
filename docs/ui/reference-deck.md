Реализация в логическом окне1090×650 масштабируется целиком; фон/рисунки свои. Четыре ряда по мастям♠♥♣♦, ранги A,K,Q,J,10→2. Карты перекрываются и слегка поворачиваются. «Осталось»: полный состав партии остаётся видимым, карты вне drawPile приглушены; числа слева учитывают только drawPile. «Вся колода»: полная яркость, числа по state.cards. Вкладки не изменяют состояние партии или сохранение. Красная/синяя колода показывают текущий эффект, не жёстко заданную красную для всех партий.

Кнопки переведены на русский согласно языку проекта. Навигация вкладок стрелками/Home/End; закрытие Назад/Escape/AndroidBack. Переключение на следующий диалог очищает класс deck-dialog.

Ограничения: ядро пока не реализует весь каталог модификаций/изданий/мастей; отображение соответствующих новых сущностей потребует расширения вместе с ядром, а не фиктивных счётчиков. Состав изображений следует настоящей изменённой колоде, не всегда52.

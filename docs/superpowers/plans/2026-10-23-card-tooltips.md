# Подсказки рядом с картой

Прямое требование пользователя: подсказка любой карты возле выбранной карты, без кнопки закрытия, скрывается следующим нажатием в любом месте. Нажатие другой карты показывает её справку, повторное нажатие той же закрывает; клавиатура/Escape сохраняются. Выбор игральных карт, покупка/использование и drag не меняются.

- Общий небольшой модуль card-tooltip.js: положение справа/слева/сверху с ограничением границ экрана, capture-dismiss и единая активная подсказка.
- Коллекция: удалить hover/кнопку/страницы описания, показать полный текст рядом с целью; обновить прямой показ.
- Партия/магазин/наборы: подключить тот же модуль; для игральной карты короткое нажатие показывает справку после рендера выбора, drag скрывает.

# П-05н — джокеры колоды, денег и карт в руке

Утверждённая цель: полный каталог и точные механики загруженного APK, собственное существующее оформление. База apk-reference 043d8bbe, 424 теста ядра. Это очередной связанный этап существующего плана, без пересогласования архитектуры.

1. Из card.lua/game.lua извлечь девять эффектов: Baron, Shoot the Moon, Flower Pot, Seeing Double, Stone Joker, Steel Joker, Bull, Driver's License, Bootstraps. Проверить порядок, ослабления, Wild/Stone и рациональные коэффициенты.
2. В src/content/jokers.js и src/core/score.js добавить обработчики в существующие фазы. В src/persistence/save.js сохранить и проверить необходимый контекст до розыгрыша: удерживаемые карты, деньги, счётчики. Положительные/отрицательные/граничные тесты до реализации; покупка, продажа, reload, изменение колоды после Glass.
3. В src/content/shop-display.js добавить русские описания существующим форматтером. Браузерный сценарий проверяет покупку/подсказки, разыгрывание, сохранение и повторную загрузку.
4. Независимое ревью по Lua источнику; полный core, offline/config, browser/Android CI. Публикация через GitHub API в ветку от базы, PR в apk-reference, слияние только после зелёных проверок.
5. Обновить STATUS, ROADMAP, docs/backlog/progress, manifest/parity для проверенной партии. Полноту игры и физическую Android приёмку не заявлять.

Параллельно независимые подготовительные задачи: генератор Arcana (полный пул, не включать lifecycle преждевременно); точные спецификации финальных боссов/победы/Endless. Эти результаты не означают готовый пользовательский функционал.

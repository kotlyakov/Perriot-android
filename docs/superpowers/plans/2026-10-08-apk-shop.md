# APK shop implementation plan

> **For agentic workers:** Use superpowers:executing-plans or subagent-driven-development. The existing user-approved APK specification and ROADMAP authorize this continuation.

**Goal:** Replace the placeholder shop with original-pool deterministic generation, safe transactions and its approved layout, then advance to the next blind.

**Architecture:** Pure original-RNG producers return offers and a new RNG snapshot. Dispatch commits changes once; persistence stores inventory, inputs and RNG before UI animations. Existing saves keep their previous behavior.

**Tech Stack:** Existing JavaScript modules, node:test, HTML/CSS, Kotlin/WebView and Actions.

**Spec:** APK_REFERENCE_SPEC.md, docs/apk-findings/shop-generation.md, ROADMAP.md.

## Global constraints

- Preserve 0.4.6; develop in apk-reference. Original APK/source/art remain private reference material.
- Full original pools; never restrict random selection to implemented effects.
- Unsupported effects must never charge money or mutate state. Effect completeness remains an explicit open task until every handler is verified.
- Existing approved field geometry, Rubik and gestures remain intact.
- Saving/reloading must not regenerate offers, consume random numbers or double-charge.

## Review focus

- Fresh versus unlocked profile: explicit pool conditions, including UNAVAILABLE positions.
- Normal versus reduced motion: original immediate random consumption affects first Buffoon variant.
- Duplicate offered/owned centres: construction and removal change eligibility.
- Revision races and failed purchases: no money, inventory or RNG change.
- Reloading a shop: byte-stable offers and future random streams.

## Task 1 — Full conditional producer

Files: src/content/apk-shop-catalog.js, src/core/apk-shop.js, tests/core/apk-shop.test.js, scripts/reference-rng/export-shop-catalog.py.

Interfaces: createApkShopContext(options); chooseApkVoucher(rng,context) returns voucherId/rng; generateApkShop(rng,context,options) returns offers/rng/firstShopBuffoon; rerollApkShop(rng,context,options) returns main/rng. Offers use id, entityId/originalKey, set, edition string, bigint cost/sellCost.

- [ ] Write strict tests against all six independent native fixtures.
- [ ] Export factual catalogue without original source; implement complete sorted pools, conditions, key order, prices and immediate global draws.
- [ ] Verify every fixture, purity and malformed input rejection; independently review the producer.

## Task 2 — Run and persistence integration

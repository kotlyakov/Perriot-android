## Проверка

Повторно выполнен npm test в распакованном проекте: 56 тестов, 56 успешно, 0 ошибок. Включён полный перебор стандартных пятикарточных рук и сохранения/RNG. Тесты проверяют существующий прототип, а не полное соответствие Balatro. Android-устройство, новые UI-прогоны и сборка APK в этой сессии не проверялись. Старые отчёты не считаются новой проверкой.

## Существенные отличия

- Собственные джокеры и испытания вместо полного каталога оригинала.
- Ограниченный пул боссов; Endless отсутствует в контракте загрузки (анте ограничен 8).
- Запрет повторного получения проданного джокера действует до конца забега; нужен пересмотр относительно оригинальных пулов и исключений.
- Debuff исключает карту из определения руки; необходимо проверить и изменить по спецификации оригинала.
- Прототип использует фиксированный hash для шансов Lucky/Glass; необходима проверка механики случайных исходов и сохранения RNG.
- Сохранения имеют девять уровней комбинаций и максимум пять джокеров; нужны новые версии схемы для скрытых рук, Negative и изменяемой вместимости.
- Прогресс старых собственных сущностей нельзя автоматически объявить разблокировками оригинального каталога.

## Решения перед реализацией

1. Подтвердить: продолжение существующей Android-игры либо отдельная новая копия. Не выбирать другую платформу автоматически.
2. Название «1.9» считать обозначением запрошенного результата, а не доказательством версии оригинальной игры. Точное значение ещё не подтверждено.
3. Предъявить спецификацию расширения ядра и миграции сохранений; после её рассмотрения подготовить план реализации.
4. По AGENTS-2 показать три сопоставимых варианта своего оформления до массового производства рисунков. Уже утверждённые изменения 0.18 повторно согласовывать не требуется.

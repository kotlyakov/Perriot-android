- Не менять утверждённый визуал, механику, скорость анимаций и сохранения без регрессионных проверок.

## Начальные гипотезы (НЕ подтверждённые причины)
- `src/ui/app.js`: toggle() вызывает общий render(), затрагивая несколько экранных подсистем.
- `src/ui/field.js`: renderField() пересоздаёт элементы руки и pointer-обработчики.
- `src/ui/play-animation.js`: ожидание finished у анимаций требует проверки отмены.
- `src/ui/flame.js`: постоянный requestAnimationFrame при активном пламени.
- `src/ui/layout.js`: ResizeObserver плюс resize/visualViewport resize.

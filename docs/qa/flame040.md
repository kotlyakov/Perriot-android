# Пламя над двумя счётчиками — 0.4.0

Обновлён только src/ui/flame.js. Вместо единого оранжевого огня теперь две самостоятельные области: синяя/голубая/светлая над chips (x3–114), красная/оранжевая/жёлтая над mult (x147–258). Промежуток над × пуст. Рисунок процедурный, без изображений или зависимостей: пять широких колеблющихся языков разной высоты и ширины на каждой стороне, цветные внешние контуры, горячие светлые внутренние языки и соединяющее основание. Движение меняет высоту и наклон языков; reduced motion оставляет статичный кадр.

API showFlame, flameHeight и logBigInt сохранён. Высота растёт логарифмически, ограничена 62 логическими пикселями (знаменатель отклика изменён с log+6 на log+2 для более заметного роста) и продолжает изменяться для огромных BigInt. Canvas 274×68, основание y67, все языки дополнительно обрезаны по собственной области и y>=5. Состояние игры не затрагивается. Защита текста названия руки и CSS слоя выполняются основным исполнителем.

## Проверки

- node --test tests/core/sort-animation.test.js: 3 теста прошли, включая монотонность и ограничение на тысячезначных числах.
- Дополнительные прямые assert проверили нулевое пламя на пороге/нулевом target, конечную монотонную высоту для score до 10^10000 и logBigInt(10^10000)=10000.
- Настоящий Chromium, обычное движение и reduced motion: прочитаны пиксели canvas для 301/300 и 10^500/300. В промежутке x114–146 ровно 0 непрозрачных пикселей; левая область имеет синий оттенок, правая красный; minY>=5. Огромный score создаёт более высокое пламя. После визуального замечания основной исполнитель запросил более широкие/неровные языки и более быстрый отклик. Финальная версия повторно проверена в Chromium reduced motion: промежуток над × пуст, оба цвета сохранены, верхняя граница y>=5, пламя монотонно выше для 301, 10^6 и 10^500 очков при target300. Высоты API:10.0375,43.1692,61.7918.

Физический Android не проверялся. Соответствие новым референсам оценивает основной исполнитель после интеграции CSS и визуального просмотра; проверка здесь фиксирует геометрию, цветовые области и числовые пределы.

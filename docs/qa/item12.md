## Проверочный режим

В «Играть → Новая игра» ввести13031990. Все15колод,8ставок и20испытаний доступны немедленно; удаление/изменение сида возвращает реальные условия профиля. Для испытаний сначала ввести сид в новой игре, затем переключиться на вкладку «Испытания». Любая выбранная колода/испытание начинается ровно со$100, включая Yellow. Во время такого забега коллекция из главного меню раскрывает все предметы. Предметы доступны в игровых пулах по обычным правилам появления, редкости, вместимости, предварительных ваучеров и запретов испытания; вещи не выдаются автоматически в инвентарь.

Разблокировки/победы/отметки испытаний профиля не подменяются. Запись использования остаётся по существующим правилам seeded-партий. Продолжение не сбрасывает баланс к100. Удаление временной функции после приёмки — отдельная правка, seed и сохранения сейчас работают штатно.

«Налог на роскошь»: $100 по правилу самого испытания снижает руку до0; интерфейс показывает это до запуска. Исправлен стартовый ledger challengeLuxuryTax, чтобы такой отрицательный реальный размер руки корректно сохранялся. Для обычного прохождения этого испытания используется обычный режим. Это ограничение фиксированного проверочного баланса, не скрытая подмена правила.

База: ветка fix/enhancement-visuals, HEAD083c3e2b до этого пакета; последний выданный APK0.4.56. Пользователь утвердил расположение У-57 и потребовал целое слово «Применить». ## Что изменено

- У-55/60: короткое касание руки не создаёт подсказку; удержание350мс показывает её. Выбор целей Arcana/Spectral теперь обновляет руку/доступность действий на месте, не пересоздаёт карты набора, руки и owned. Декоративные материалы читают геометрию максимум раз за кадр и пропускают обычные карты; дубли resize не пишут прежние стили; Canvas-пламя отменяет RAF при скрытии/нуле, заменяет отсоединённый canvas. Утверждённая графика/порядок расчёта/RNG сохранены.
- У-56: новая партия шире608→760 при той же высоте/шрифтах. В Continue исправлен конфликт CSS, сжимавший блок ставки в40px, и перенос последнего символа сида. Главная и настройки не переделывались. Предположение об общем переполнении высоты610 не подтвердилось и не является основанием правки.
- У-57: длинная покупка сверху, квадратная продажа справа вверху, вертикальная область применения под ней. Карты из Standard/Buffoon берутся в верхнюю область; расходники применяются справа. Там же доступна атомарная покупка с применением, включая заполненный карман расходников. Если самому эффекту требуется место/цель, отказ не списывает деньги. Под картами больше нет кнопок действия. Для выбранной расходной карты правая общая область также доступна с клавиатуры/касания; полный набор областей появляется при drag. Перестановка собственных карт не превращается в попытку покупки. Геометрия release проверяется по его координатам, без нового чтения DOM.
- У-51а/б: билеты магазина и награды пропуска используют общие иллюстрации коллекции. Сохранены читаемые цена/подсказки/отрывная часть билета.
- У-58: все32набора описывают своё семейство, число предложенных карт и число выборов. Временная заглушка для наборов удалена.
- У-40а: основной блок подсказки не растягивается по высоте дополнительных плашек; Колесо фортуны проверено отдельно.
- У-59: найден и воспроизведён дефект replay whitelist — действие SKIP_BLIND из UI содержит blindId, которого декодер истории не разрешал. История испытания после такого пропуска не сохранялась. Исправлен whitelist, включая новое BUY_AND_USE_SHOP_CARD. Проверены оба пропуска с Charm и сохранение/продолжение во всех20испытаниях. Полные карманы не блокируют открытие пяти семейств бесплатных наборов. При попытке забрать Джокера без места карта возвращается, появляется краткое «Нет места для Джокера»; можно продать своего и повторить. Есть «Пропустить набор». Общая плашка «Действие недоступно» заменена конкретной причиной; повреждённые/устаревшие действия по-прежнему безопасно отклоняются.
- У-61: использование Таро/Планеты/Спектральной сопровождается оранжевым/голубым/разноцветным всплеском; раскрытие соответствующих наборов подсвечивает появление карт теми же цветами. Скорость игры и reduced motion соблюдаются. Сохранение предшествует анимации, UI занят до её окончания.
- У-62: убраны внутренняя SVG-рамка/уголки и внешняя рамка расходных карт; бумага насыщеннее. Сами утверждённые сцены не заменялись. Состояние busy сохраняет цвета; выбранная карта имеет отдельное выделение.

# Независимая проверка окна колоды — 0.3.5

Проверен новый экран по приложенному скриншоту 1000029731.png (1536×709). Окно, верхние две вкладки с указателем выбранной, левая информация о колоде и статистика, столбец номиналов, четыре ряда перекрывающихся карт и нижняя кнопка «Назад» воспроизводят структуру референса. Рисунки и палитра сохраняют согласованный собственный стиль. Это проверка данного окна, не утверждение полного соответствия всей игры.

## Проверки в настоящем Chromium

Запущен tests/ui/deck-reference-check.mjs с локальным сервером и toolchains/browser/chrome-linux/headless_shell. Проверены 1536×709, 915×412, 568×320, 360×800, 1024×600 и 2400×1080. Последний прогон после исправления высоты рядов: все шесть размеров прошли. Карты и нижняя кнопка остаются внутри окна, ряды перекрываются как в референсе. Визуально просмотрен artifacts/deck-reference-preview.png: заголовок/описание, статистика и номиналы читаемы, наложения текста нет.

Fixture содержит фактическую колоду из 51 карты (удалена 2♣), восемь карт в руке. Проверено: четыре ряда, 51 изображение; вкладка «Осталось» затемняет восемь недоступных карт и показывает 3 туза / 7 фигур / 33 числовые карты. «Вся колода» убирает затемнение и показывает 4 / 12 / 35. Клавиша ArrowLeft возвращает «Осталось». Сохранённое состояние побайтно не меняется при переключении вкладок. «Назад» и Escape закрывают окно; повторное открытие работает. Ошибок JavaScript в прогоне нет.

## Замечания, выявленные до исправления

1. На 2400×1080 нижний веер выходил за границы сетки: высота содержимого и повороты карт превышали доступную высоту. Исполнитель уменьшил высоту рядов/карт; повторный прогон всех размеров прошёл.
2. После «колода → Escape → Параметры» оставался класс deck-dialog: заголовок «Параметры» был скрыт, применялась геометрия окна колоды. Независимо воспроизведено в Chromium: open=true, className=deck-dialog, titleDisplay=none. Исполнитель добавил сброс класса при закрытии и определение типа окна по его содержимому. После исправления независимый повторный прогон всех шести размеров с проверкой «колода → Escape → Параметры» прошёл: deck-dialog отсутствует, заголовок следующего окна виден.
3. Проверка сначала использовала жёсткий порт 4173 вместо PREVIEW_URL. Исполнитель исправил URL; теперь штатный scripts/check-ui.mjs со случайным свободным портом работает.

## Ограничения

Проверка выполнена в Chromium на настольных и мобильных размерах, не на физическом Android. Механики улучшений/модификаторов будущего полного каталога текущим прототипом ещё не реализованы. Изменение арт-стиля принято заранее; точное совпадение оригинальных карт не заявляется.

Итог: обнаруженные замечания исправлены; финальный независимый прогон завершился с кодом 0. Открытых замечаний по проверенному окну нет.

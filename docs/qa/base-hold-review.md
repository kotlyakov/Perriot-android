# Независимая проверка базовых очков и удержания — 0.4.1

После восстановления проекта заново создан независимый tests/ui/base-hold-review-check.mjs. Проверки выполняются в настоящем Chromium на 915×412 для мыши, CDP touch и touch reduced motion.

Проверяемые требования: короткое нажатие выбирает карту без подсказки; появление подсказки измеряется браузерным MutationObserver не ранее330ms при production-таймере350ms; после отпускания подсказка сохраняется1900ms без прежнего timeout; нажатие на пустом поле закрывает её. Удержание не переключает выбранность.

Отмена pointer до окончания таймера проверяется с ожиданием500ms: нет осиротевшей подсказки/dragging, сохранение не изменилось. Для удержание→перетаскивание→отпускание анимации240ms принудительно остановлены на10ms: подсказка остаётся до завершения движения, после возобновления удаляется. В reduced motion постановка завершается сразу и подсказка исчезает без зависания.

Fixture: стрит уровня3. Выбор пяти карт показывает базовые90 очков и название «Стрит», а не окончательные130. При розыгрыше DOM-наблюдение во время присутствия сыгранных карт проверяет90→130 без промежуточного0. Окончательный idle-render исключён из наблюдения, поскольку после завершения розыгрыша пустой выбор закономерно очищает панель.

Production-файлы проверяющим не изменялись. Физическое Android-устройство не использовалось.

Итог: новый независимый прогон завершился кодом0; все три режима прошли перечисленные проверки. Открытых замечаний нет.

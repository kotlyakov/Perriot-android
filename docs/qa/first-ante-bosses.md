# Восемь боссов первого анте — 09.10.2026

Новый забег проходит малый → магазин → большой → магазин → уже выбранный босс → выплата → магазин второго анте. Запуск второго анте пока отключён. Полный пул 28 боссов не сокращён.

Работают: Крюк, Трефа, Кандалы, Экстрасенс, Побуждение, Окно, Голова, Столп. Ослабленные карты участвуют в распознавании комбинации, но не дают своих фишек и не вызывают покарточные эффекты джокеров. Независимые эффекты 32 поддержанных джокеров сохраняются. Экстрасенс расходует руку менее чем из пяти карт за ноль очков; Кандалы уменьшают размер руки на один и восстанавливают его при выплате. Столп использует снимок всех ранее сыгранных карт анте, включая не вошедшие в подсчёт; обычный сброс не записывается. Крюк выбирает до двух несыгранных карт без замещения по постоянному порядку создания, сбрасывает их в порядке руки и не тратит сброс.

Состояние босса и история сохраняются. Загрузка старого забега без истории не выдумывает прошлые карты и не разрешает босс. После победы история очищается, ваучер обновляется и магазин использует ante2/Voucher2/cashout2. Метаданные завершённого раунда остаются ante1 до ещё не реализованного следующего перехода; HUD магазина показывает ante2.

228 тестов ядра PASS. Есть RED→GREEN по семи группам эффектов, повреждённому Hook состоянию и новому анте магазина. Независимый эталон: 135 операций исходного press_play и discard handler под закреплённым нативным LuaJIT, проверены выбранные карты, порядок фактического сброса, поток hook и следующий глобальный RNG. Исходные Lua/ресурсы не включены в репозиторий; это изолированные функции, Android-оригинал не запускался.

Итоговое независимое ревью нашло P2: сохранение с нештатным ID карты Крюка принималось, play мог выбросить исключение и оставить UI занятым. Исправлено RED→GREEN: canonical identity проверяется для boss state, Hook failure возвращает атомарный отказ, входы не изменяются. Других существенных замечаний ревью не дало.

UI: вход из магазина большого блайнда, выбор/начало босса, собственная отметка ослабления и подсказка, русский заголовок/награда, возобновление на трёх размерах, отсутствие пропуска босса, безопасная блокировка legacy, forced-discard анимация и выплата/магазин ante2. Итог CI/коммиты в STATUS.md.

Охват — обычные немодифицированные игральные карты и прежние 32 эффекта джокеров. Wild/Stone, печати, изменённые/добавленные карты, новые джокеры и боссы других анте не включены в этот блок. Дальше нужны остальные эффекты, переход анте и полные пропуски/теги. Физический Android и пользовательская приёмка не выполнены.

Первый CI нового сценария остановился на неверном ожидании: после игры выбор пуст, поэтому кнопка игры остаётся disabled. Условие заменено на доступность сортировки плюс размер руки 8; производственный код не менялся.

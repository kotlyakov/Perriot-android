# П-04в — переход ко второму анте

Авторизация: поручение взять следующую функцию утверждённого плана. Добавлены малый и большой блайнды второго анте. Босс второго анте остаётся отключён до реализации остальных необходимых эффектов; пулы не сокращены.

Источник: docs/apk-findings/next-blind-lifecycle.md и повторный просмотр cash_out/orbital_choices загруженного APK 1.0.1n-FULL. Исходные Lua в репозиторий и релиз не включены. Порядок: Voucher2 → cashout2 shuffle → два Tag2 → boss с историей → магазин. На LEAVE_SHOP выбираются три orbital; ваучер и магазин повторно не генерируются.

Цели второго анте 800/1200, награды 3/4, проценты и оставшиеся руки — прежние. Раунды 4/5; джокеры, деньги, колода и уровни сохраняются. История карт анте очищается после первого босса.

Локально 231/231 ядра PASS; новые три теста сначала FAIL на отсутствующей функции, затем PASS. Проверены обе колоды, сериализация/загрузка до и после перехода, неизменность входа, повторные действия, деньги/ваучер/nr2, раунды4/5 и старый магазин. UI next-ante добавлен в CI: 1536×688, 915×412, 360×800, реальные кнопки/цели/tooltip/reload/блокировка босса.

Локальный UI не запущен: Chromium отсутствует, установка возвращает повреждённый ZIP. CI и ревью пока ожидаются. Физический Android и пользовательская приёмка не выполнены.

Старый магазин босса без nextAnteBlinds продолжает без повторной выплаты/генерации магазина; новые выборы создаются однократно при LEAVE_SHOP. Совпадение с историческим порядком RNG оригинала для такой миграции не заявляется.

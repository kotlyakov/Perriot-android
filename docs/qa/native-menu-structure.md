# Окна — повторная итерация по исходным определениям Balatro

Пользователь отклонил прежний показ. Основа структуры — UI_definitions.lua из предоставленного APK. Чужие исходники и рисунки в продукт не переносились. Собственный стиль B/Rubik сохранён.

| Окно | Проверяемая структура оригинала | Реализация |
|---|---|---|
| Опции | 2317: вертикальный список, условные пункты забега/главного меню, сид/копирование только seeded | menu-windows createOptionsView, app context |
| Настройки | 2373/2407: Игра/Графика/Звук; циклы, переключатели и 3 ряда громкости | createSettingsView; неподдерживаемые параметры серые |
| Настройка колоды | 2621/2653: 4 масти, K/Q/J, цикл рисунков, контраст | createCustomizeView; смена рисунков пока недоступна |
| Статистика | 2699: 6 рекордов слева, прогресс и переход к статистике карт справа | renderStatsView, отдельна от выбора профиля |
| Победа/поражение | 2861/2974: персонаж слева, итоги справа; победа с Endless снизу, поражение с парой действий | createEndView; исторические незаписанные показатели явно — |
| Партия | 3156/3192/3241: один список рук с уровнем, Chips×Mult и числом розыгрышей; вкладки блайндов/билетов/ставки | createRunInfoView, действительные цели/награды/handUsage |
| Коллекция | 3609: отдельный двухколоночный индекс, расходники сгруппированы; категории имеют собственную матрицу | renderCollectionView без боковой навигации в категориях |
| Новая/продолжить | 5167/5837: вкладки, общий блок стопки/описания/побед со стрелками, ставка, seeded и Play, отдельный Back | renderStartScreen, actual savedState, явное продолжение |
| Профили | 5209+: 3 профиля, просмотр, прогресс слева, отдельная загрузка справа | renderProfileView; просмотр не меняет профиль |
| Испытания | 5068/5377: обзор прогресса → список по10, инвентарь/параметры, Правила/Запреты/Колода | renderStartScreen challenge views |

Внешние размеры различаются по содержимому и масштабу игры. Это структурная сверка исходного UI, не подтверждение пиксельного равенства нативному рендереру. Для него ещё нужен запуск оригинала на сопоставимом экране.

Ограничения: прочие рисунки/настройки/сброс профиля пока недоступны; старые сохранения не содержат подробной сводки runSummary и лучшей руки забега. Незаписанные итоги не подменены вымышленными числами. Эти пункты не считаем закрытыми.

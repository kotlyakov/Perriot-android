## Изменено

- Собственные звуки для выбора/раздачи/сброса, покупок/продаж, переброса, открытия наборов/применения расходников, этапов подсчёта, выплаты и итога раунда. Детерминированные правила/RNG не затронуты: UI синтезирует звук после сохранения принятого действия. Неверные действия не воспроизводят звук успешной покупки.
- Собственная16-шаговая музыка синтезируется без записи, сети и сторонних файлов. AudioContext создаётся по жесту; отсутствие выхода не блокирует игру. Громкость музыки/эффектов регулируется отдельно,0% отключает канал.
- Настройки сохраняются отдельно от игрового current/backup. Android audio.json: AtomicFile, предел1024, два числовых ключа0..1, валидация до записи. Отказ записи возвращает прежний регулятор и показывает сообщение.
- При visibility/pagehide/native onPause музыка и голоса останавливаются; при возврате возобновляются с учётом асинхронного suspend. Исторические эффекты при заблокированном выходе отбрасываются. Голосов не более48; быстрый reduced-motion подсчёт ограничивает частоту сигналов.
- Три издания имеют различимые собственные переливы: foil-полосы, holographic-переход, polychrome-спектр. Reduced-motion оставляет покрытия статическими. Добавлен видимый focus для клавиатуры. Сохраняются геометрия и стиль B; инерция З-03 не переписана.

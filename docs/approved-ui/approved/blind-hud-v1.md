# У-44а — блок текущего блайнда, утверждено25.10.2026

Пользователь принял предложенный макет сообщением «Пойдет». Внедряется только этот срез игрового окна; У-44 в целом остаётся открытым.

Сохранить общий HUD и его соседние элементы. Для босса показать имя в верхней плашке, ниже — постоянное условие из актуального каталога, затем жетон блайнда, цель и награду. Жетон текущей ставки разместить рядом с требуемыми очками, подпись ставки — под блоком цели. Цвет ставки берётся из общего каталога8ставок. При отключении босса явно показать отключение вместо действующего условия. У малого/большого блайнда не выводить условие босса.

Не менять цель, награду, механику босса, RNG и сохранения. Длинные условия/имена и крупные числа не обрезать; весь блок должен помещаться на1536×688,915×412,568×320. Условие и подпись должны исчезать вместе с родительским блоком блайнда в магазине/наборах и других фазах.

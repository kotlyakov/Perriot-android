## Reading the contracts

Every calculate_joker branch first excludes debuffed sources. Copying must resolve the actual mutable target and original activating source afresh per context, with the existing bounded Blueprint/Brainstorm recursion. “Noncopied” means the particular mutation is excluded when context.blueprint is set; copied main output remains allowed unless stated otherwise. Passive add/remove, own cashout dollar bonus, pool membership and global predicates are not copied. Do not reject all effects solely by blueprint_compat metadata: native forwarding has no metadata gate.

All growth starts at Mult0, chips0 or ×1 unless a row states otherwise. Ability creation `card.lua:273–338` initializes extra resale value0, copied centre extras, and acquisition global hand counter; Invisible age0, Caino×1, Yorick23, Loyalty5. Per-instance mutable counters, targets, added/removed card snapshots, actual RNG state and pre-score inventory must survive save/replay. Do not infer past state from inventory after a removal.

“individual” means scoring area unless “held” is explicit. Recognition/scoring selection is computed before ordered before effects, then own card effects and individual activations/repeats, held effects/repeats, Joker main/edition/other-Joker effects, destruction, after. Native main's generic stored × branch precedes specialized main branches. Money effects feed native dollar buffer and same-hand money readers in order. Repeated cards rerun random/growth effects, not multiplied cached results.

Capacity is owned count plus pending creation buffer, compared with effective capacity including Negative. Reserve before discovering subsequent creations; do not draw RNG for a short-circuited no-capacity branch. Native creates may return unsupported item8 Spectral content: creation/ownership is still a real item7 effect, while applying an unimplemented Spectral stays explicitly unavailable. Do not silently filter generated pools to implemented effects.

## Judgement

`c_judgement` is the sole additional consumable effect in item7. Native `card.lua:1416–1427,1559–1565`: can use only when an effective Joker slot is free (or the consumable itself is in Joker area, a native context not normally exposed here). Successful use schedules one ordinary `create_card('Joker', …)` with suffix `jud`, not legendary and no forced rarity, then add-to-deck and emplacement. It uses the full native eligibility/pool and edition/sticker construction, including Showman and current locks/gates; never choose uniformly from 150 or only supported centres. Failed capacity query/use consumes neither the card, money nor RNG. Successful use counts as a Tarot use once and updates Fool history consistently with other Tarots. Existing successful-use callback must notify Constellation/Fortune Teller/Glass contracts at the native point, with consumed snapshot preserved. Native create factory is `functions/common_events.lua:2116+`; independent fixtures must pin rarity, selected centre, edition/sticker, seed-state changes and irreversible add hooks. Full Soul/Wraith effects remain item8.

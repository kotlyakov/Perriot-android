# №11 — финальные UX, графика и звук

Основа: docs/art/art-bible.md, docs/progress.md (строка 11), docs/backlog.md. Пользователь поручил №11 после слияния PR42. База 7cbf568. Утверждённый стиль B и геометрию сохраняем.

Решение исполнителя: собственный Web Audio синтез вместо внешних аудиозаписей; работает без сети и не увеличивает APK файлами звука. Настройки музыки/эффектов хранятся отдельно от игровых сохранений, в Android — через существующий мост с отдельным ограниченным AtomicFile. На старте звук ждёт жест пользователя; при сворачивании останавливается. Отказ аудиоустройства не мешает игре.

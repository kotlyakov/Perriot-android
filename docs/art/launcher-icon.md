# Иконка Пьеро — релиз0.4.62

Создана03.11.2026 по поручению пользователя как собственная иллюстрация. Промпт: theatrical Pierrot face, ivory playing card, burnt-orange/teal cap, deep green filled background, clean letterpress/linocut contours, no text, readable at small icon size. Использована встроенная генерация изображений; чужие логотипы или ресурсы оригинального APK не использованы.

Источник поставляемых размеров — rustore/media/icon-512.png. Androiddensity48/72/96/144/192PNG и adaptiveforeground432PNG с полями. Для Android8.0+ используются adaptiveiconиroundIcon, фон#0B3D35. Никаких изменений рисунков внутри игры.

Служебная конвертация размеров сохраняет изображение; исходная сгенерированная иллюстрация отдельно доступна в беседе. RuStoreиконка непрозрачная512×512. Ключи подписи к этой папке отношения не имеют.

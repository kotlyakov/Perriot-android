## Результат

Доступен цикл первого анте с восемью боссами, затем магазин → малый второго анте (800) → магазин → большой второго анте (1200) → магазин. Раунды 4/5. Босс второго анте пока отключён; полный П-04 остаётся открытым.

После первого босса сохраняются следующие теги и босс из полных пулов 24/28, с историей использования. Порядок: Voucher2 → cashout2 shuffle → Tag2 дважды → boss → магазин. Три orbital выбираются при выходе в следующий экран выбора и сохраняются. Повторная загрузка ничего не перебрасывает, ваучер не перевыбирается на выходе; деньги, покупки, уровни и колода сохраняются. История карт анте очищается.

Старый магазин после босса без `nextAnteBlinds` продолжает без повторной выплаты/пересоздания магазина. Новые выборы создаются однократно на выходе; историческое совпадение порядка RNG с оригиналом для такой миграции не заявляется. Старые забеги без истории карт сохраняют прежнюю безопасную блокировку босса.

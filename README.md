# Пьеро — Android

Проверочная версия **0.4.49-preview**, versionCode62, пакет `ru.cardcascade.game.preview`. Ветка `feat/menu-motion`; актуальные результаты и ограничения — [STATUS.md](STATUS.md), оставшиеся задачи — [BACKLOG.md](BACKLOG.md).

25.10.2026 пользователь утвердил первый набор всех150джокеров: собственные рисунки с картами/фишками в стиле «Печатная мастерская», отдельное поле полного названия. Главное меню и настройки утверждены24.10 и восстановлены с точными паспортами в `docs/approved-ui/`. Поздние варианты рисунков сохранены в Git и не используются. Новая сборка включает утверждённыйUI и работающую скорость0.5/1/2/4. Прочие открытые визуальные задачи остаются в бэклоге.

В проекте реализованы каталог150джокеров,15колод,8сложностей,20испытаний, магазин/наборы/расходники, профили/открытия, сохранение и воспроизведение партий. Это проверочная сборка; полная точность исходной игры, все визуальные экраны и физическийAndroid ещё не заявляются завершёнными.

Требуются Android8/API26+ и современный WebView с ESmodules/BigInt. Сохранения используют прежний packageID/форматы. Фактическая подписьAPK и проверки фиксируются в отчёте сборки; совместимость обновления определяется сертификатом.

Локально: Node22+, `npm test` без установки зависимостей; `npm run preview` — http://127.0.0.1:4173. UI-проверки используют Playwright/Chromium. Android: `npm run android:assets`, затем `bash android/build-debug.sh`; JDK17, SDK36/BuildTools35.0.0, закреплённый GradleWrapper. Генерируемые assets/artifacts не редактировать вручную. CI выполняет свежую Gradle-компиляцию, проверку подписи/выравнивания и сохраняетAPK как artifact. Детали — `docs/android-build.md`.

# Пьеро — новый Android-проект

Промежуточная версия 0.4.4-preview. Цель — механики и компоновка целевой Balatro Android 1.9 с собственным оформлением «Печатная мастерская». Новый проект создан отдельно, старый код 0.18 не использован.

Работает один малый блайнд: выбор до пяти карт, сортировка, перетаскивание, розыгрыш, сброс, добор, подсчёт с трассой, победа/поражение и продолжение. Ядро распознаёт 12 комбинаций обычных карт и четыре простых джокера; получение джокеров ещё не подключено. Есть проверенные current/backup сохранения. Награда, магазин, следующие блайнды, полный каталог и режимы ещё не реализованы.

APK собран средствами Android; установка и работа на физическом устройстве ещё не проверены. Минимум API26 и современный Android WebView с ES modules/BigInt. APK имеет пакет ru.cardcascade.game.preview, versionCode14 и debug-подпись. Это промежуточная проверочная сборка.

Ядро: Node22+, `npm test`, без установки зависимостей; 91 тест. UI: `npm run preview`, открыть http://127.0.0.1:4173. `npm run preview:export` создаёт автономный artifacts/field-preview.html. `npm run test:ui` самостоятельно запускает preview и проверяет браузер; нужны Playwright и Chromium, при нестандартном расположении бинарника задать CHROMIUM_PATH. Проверены mouse/touch/keyboard/drag, повторные действия, recovery, отказ записи, resize и автономный HTML без сети. Подробности: docs/qa/browser-runtime-review.md.

Android: `npm run android:assets`, затем `android/build-debug.sh`. Настоящий Gradle Wrapper включён и закреплён checksum; требуются JDK17 и Android SDK36/Build Tools35.0.0. Инструкции: docs/android-build.md; протокол сборки: docs/android-toolchain-attempt.md. Генерируемые assets/artifacts не редактировать вручную.

Рабочий план — ROADMAP.md, передача состояния — docs/progress.md. Начальные $4 — explicit fixture кандидата, не подтверждение спорного правила. Геометрия1536×688 измерена вручную, другие аспекты используют uniform letterbox; полная pixel parity и остальные экраны ещё открыты. Связь версии приложения1.9 с исследовательской базой правил1.0.1o-FULL требует подтверждения. Оригинальные скриншоты не входят в игровые assets.
